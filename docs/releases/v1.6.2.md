This patch updates **macOS Glass only** (macOS 26+, Apple Silicon + Intel universal package).

本轮仅更新 **macOS Glass**。Normal 和 Linux 保持 v1.6.0，Windows 保持 v1.5.12；安装器继续提供各平台原有版本。

### 更新内容 / Changes

- **Claude 本机授权 / Claude local access**：修复没有额度数据时仍只提供“连接 Claude”网页登录按钮的问题。空状态现在始终提供“授权读取本机登录”，网页登录作为独立备用入口；只有主动点击时才申请系统权限。优先尝试已有 App 登录、现有 OAuth 和近期缓存，无需额外安装 CLI。
- **Grok Bot 授权 / Grok Bot authorization**：重启后尝试静默复用已获准的 Keychain 读取；后台不再通过可能弹窗的 security CLI 取凭据。解密失败、格式不兼容、网络失败和接口拒绝分别处理，避免授权成功后继续要求授权。支持现行多账号、scoped:v1 和旧单账号存储格式；授权后的新请求取代旧的在途结果。
- **订阅与账号边界 / Subscription and account boundaries**：仅在接口明确确认统一订阅时展示和去重 X 共享周额度。独立 Cursor / Grok Bot 额度保持分开；存在 Grok Bot 当前账号时，Cursor 备用凭据必须匹配同一登录主体。已有 CLI、IDE、仅 Grok Bot 的来源分别处理；CLI 凭据受保护时提供对应的主动授权入口，无需安装 Grok Bot。接口明确没有 Bot 额度时不显示为“剩余 100%”。
- **补交付：Claude 网络设置 / Claude networking**：额度查询跟随系统路由，支持现有代理配置和 TUN，提供可选“必须代理”。选定代理失败后不改走直连；兼容新版只读 OAuth 账号校验，不把网络失败当作必须重新登录。
- **补交付：本机 Codex 检测 / Local Codex in Model Detect**：可复用已有 Codex 登录，明确选择型号和题包，点击后创建独立测试会话；保留部分结果和证据。不自动发题、重试或续跑，不把这条采集路径的观察冒充已校准的型号身份结论。
- **补交付：表盘交互 / Clock interaction**：修复移动表盘后的点击命中位置及透明边角穿透，并补上辅助功能点击动作。

### 使用说明 / Notes

- Claude / Grok Bot 本机读取可能需要 macOS 对当前安装版授予权限；这不是要求重新输入服务商账号密码。后台始终静默，不绕过系统权限，也不刷新或写回原应用的登录。
- 本机已通过匹配 Grok Bot 当前账号的 Cursor IDE 登录读到真实 X 统一周额度。独立 Cursor、仅 Grok Bot、重启、并发授权和账号切换路径已做回归；由于本机系统拒绝原生密钥读取，原生授权后的正向实测仍待完成。反馈用户的 Claude App / macOS 27.2 环境也尚未验证成功。
- 仅安装 Grok、没有可复用 Cursor 或 Grok Bot 凭据的订阅额度来源尚未确认；不会据此推算额度或混用其他账号的数据。
- 日志仍只读，统计及 t/s 每 3 分钟刷新的口径保持不变。未估算 Claude 云端聊天 Token。
- Public macOS packages retain the existing ad-hoc, non-notarized format. Private local signing material is not distributed.
