# Product and model icons

These marks identify their respective products and model providers. They remain
the property of their respective owners. Source URLs, application versions, and
original-file SHA-256 hashes are recorded in sources.json.

Artwork comes from official websites, official repositories, or installed
vendor application packages. It is converted to 128 px PNG with its original
colors and proportions; no logos are redrawn. Standalone marks replace decorative
app tiles where available. Monochrome Codex, Copilot, Grok and ZCode marks follow
the surrounding text color for light/dark contrast. The images are bundled, so rendering requires no network
requests and does not depend on local installations.

Appearance → Tool & Model Icons switches between official artwork and the original
Emoji presentation. The choice is saved; usage records are never rewritten.
Unrecognized names or unavailable files use the existing text/emoji fallback.
