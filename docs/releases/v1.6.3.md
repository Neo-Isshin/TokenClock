This patch updates **macOS Glass only** (macOS 26+, Apple Silicon + Intel universal package).

本轮仅更新 **macOS Glass**。Normal 和 Linux 保持 v1.6.0，Windows 保持 v1.5.12；安装器继续提供各平台原有版本。

### 更新内容 / Changes

- **Claude 本机额度 / Claude App quota**：优先读取原 App 保存的近期真实额度历史和对应组织的本地用量响应，保留实际采样时间；复用已有登录，无需额外安装 CLI。兼容现行 `limits` 与旧额度格式；同一进程复用已获准的 App 解密密钥，密钥轮换后重新读取。网页验证拦截时可重试读取额度，不反复要求授权或把拦截当作未登录。
- **铃铛未读标记 / Notification unread badge**：打开通知面板时正确确认已展示新闻的未读状态，持久保存已读记录；新新闻仍正常显示未读。再次打开时恢复适当的分类，避免已读新闻分类遮住其他通知。
- **面板边缘拉伸 / Panel edge resizing**：下拉面板与通知面板支持四边及四角拖动调整大小，鼠标靠近边缘时显示对应拉伸指针；保留尺寸记忆、屏幕边界约束及面板内原有按钮交互。

### 使用说明 / Notes

- Claude 只展示可核对的真实额度记录，保留记录时间，不估算 Chat / Cowork / Cloud Code 的 Token，也不推算重置后的额度。没有有效本机记录或可复用登录时，仍提供现有的主动连接入口；后台不会弹出授权。
- 本次已通过真实生产读取路径的离线集成测试，包括网页验证拦截后的本地记录回退、账号与组织隔离、过期及损坏数据拒绝。反馈用户那台 Mac 的在线成功读取尚未实测；不同 Claude App 版本若不保存这些记录，仍可能无法自动读取。
- Logs remain read-only; token accounting, request attribution and the three-minute t/s refresh cadence are unchanged.
- Public macOS packages retain the existing ad-hoc, non-notarized format. Private local signing material is not distributed.

### 验证 / Validation

- Swift regression: 577 passed, 26 conditional tests skipped, 0 failures. Focused production-path quota, notification and AppKit resize tests passed; live checks remain explicit opt-in.
- Golden Chromium cache fixtures cover plain JSON and zstd; malformed, stale, oversized and mismatched organization data are rejected. Automated quota tests make no external requests or model generation calls.
- Universal arm64 + x86_64 package and minimum macOS 26.0 are checked before publication; release staging tests passed.
