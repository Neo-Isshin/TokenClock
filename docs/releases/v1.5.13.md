# TokenClock v1.5.13

This release activates the self-hosted update and download endpoints in rebuilt clients.

- Version checks, release notices, installers, and macOS edition downloads now use www.ailyre.com instead of the unavailable GitHub repository.
- Pricing catalogs refresh independently from the self-hosted catalog endpoint.
- macOS Normal includes the edition-switching helper in its resource bundle.
- Includes the previously committed Claude App connection, relocated-session discovery, catalog updates, and macOS Model Detect integration.

Available now: macOS Glass universal, macOS Normal universal, and Linux x86_64 AppImage.
Windows remains on v1.5.12 until its build host is online and the rebuilt package is tested.
Existing GitHub-based clients need a one-time installation from the new endpoint to adopt it.
