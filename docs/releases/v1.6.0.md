# TokenClock v1.6

程序版本 / Application version: **1.6.0**.

## macOS Glass

- 网络工具箱增加大陆可达性 / GFW 参考：Globalping 大陆三网与境外多点 TCP 对照，只在手动点击后检测；超时和证据不足不会被标记为确认封锁。卡片注明服务来源与公开测量说明。
- 工具箱快捷按钮采用四窄一宽布局，悬停展开名称，单击直接进入；Historical Usage 移至第一行。
- 修正 t/s 长悬停说明的换行和裁切，使用独立浮层，并保留有真实数据时的 TTFT 信息。
- 菜单栏单击打开今日总结，双击按隐藏、临时置顶、遮挡状态切换；临时置顶不修改 Always on Top 设置。
- 包含本机已验证的 Codex 生成速度归属、共享订阅识别、工具箱与分享图片改进，以及 DSH / PiG 支持。

## Catalog and distribution

- 模型价格目录从 Ailyre 独立更新，更新模型及价格无需重新安装应用，也不依赖 GitHub Actions。
- macOS 安装器保留已明确配置的本地签名身份，避免更新时降级为 ad-hoc 身份。
- macOS Glass 与 Normal 均提供 Intel + Apple Silicon 预编译通用包；Linux 提供 x86_64 AppImage。
- Windows 测试机尚未联机，继续提供已经验证的 **v1.5.12**，没有将旧包改标为 v1.6。

## Downloads / 下载

- `TokenClock-glass-universal.tar.gz` — macOS 26+, Intel / Apple Silicon.
- `TokenClock-normal-universal.tar.gz` — macOS 12+, Intel / Apple Silicon.
- `TokenClock-x86_64.AppImage` — Linux x86_64, glibc 2.35+.
- [Windows v1.5.12](https://github.com/Neo-Isshin/TokenClock/releases/download/v1.5.12/TokenClock-windows-x86_64.zip).

macOS packages retain the historical **ad-hoc signed, non-notarized** format. They are precompiled and do not require Swift/Xcode for normal installation. This is not Apple Developer ID signing; first access or a changed ad-hoc build can require system approval. An explicitly enrolled local installation keeps its own signing key on that machine.

The new toolbox and menu-bar presentation changes above are specific to macOS Glass; this release does not claim identical new UI features on other editions.

## Subscription and network boundaries

- Claude local token usage is read from local logs. Online quota requests follow the macOS system route, including an enabled system proxy or TUN; this is not a mandatory-proxy/no-direct-connection policy.
- Glass distinguishes server-confirmed merged **X Subscription** shared weekly quota from legacy independent **Cursor** subscriptions. Deduplication requires the same authenticated account and observed quota window, not merely the same email.
- An unmerged X Premium+ / SuperGrok subscription is not queried through a native X billing API in this release. Renewal dates and balances are not inferred for merged subscriptions.
