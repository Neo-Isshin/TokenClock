# Glass：Claude 额度网络策略（已修正默认行为）

本轮只修改 Glass 的 Claude 额度网络路径。OAuth usage、桌面 Cookie 和独立 WebKit 登录后发起的 account / organizations / usage 查询，共用同一个代理执行器。没有修改模型判断规则、题面、参考数据或冻结回归基线。

## 行为

默认跟随系统，允许正常直连和 TUN。在订阅额度窗口的「Claude 额度网络设置」折叠项中，可选「必须代理，禁止直连」，默认关闭。设置只影响后续额度请求，切换开关不触发额外查询。

- 每次请求重新读取 Claude 配置目录的 `settings.json`、本进程已有代理变量及系统代理设置；不读取终端启动脚本、不猜测代理软件端口。
- Claude 配置与进程代理同时存在但不一致时停止。显式配置为空、格式错误或无法读取时停止，不退回系统网络。
- 使用系统代理时尊重目标域名的匹配结果。默认模式接受 DIRECT，流量由操作系统路由（包括 TUN）。只有开启「必须代理」才拒绝 DIRECT。PAC 仍未接入，无法解析时暂停，不猜测直连。
- 支持明确的 HTTP CONNECT、HTTPS 和 SOCKSv5 地址。SOCKS 使用远端域名解析形式 socks5h。
- 每次请求固定一次选定的网络路径，使用系统 `/usr/bin/curl`。有代理时固定代理；系统选择 DIRECT 且未开启强制模式时，正常使用系统路由。首参数 `-q` 禁用默认配置，清空代理绕过表，移除继承的代理/证书/调试环境变量，禁止重试和重定向；目的地址只允许固定 Claude 额度 HTTPS 路径。
- Cookie、Bearer 和代理密码经 stdin 内存管道传入，不进入进程参数、环境变量、日志或磁盘文件。TLS 正常验证，不使用 insecure。
- 连接拒绝、代理认证失败、超时、TLS 失败、传输中断或重定向均停止。失败的代理请求不改走直连，不换账户，不把缺失额度当作 0% 或 100%，不因网络保护拦截而要求重新登录。
- 单次最多 8 秒，响应最多 1 MiB；额度界面原有刷新频率和布局不变。

## 明确边界

**默认允许直连和 TUN，不按地区判断。** TUN 的接管和断网行为由操作系统及代理软件决定，TokenClock 不绑定或更改网络接口。仅开启 TUN 并不会阻止默认模式的额度查询。

**选择「必须代理」后，需要明确可使用的代理地址。** 仅 TUN、没有可识别 HTTP/SOCKS 代理地址时会暂停；可以同时启用系统代理。该可选保护不会默默开启，也不根据历史请求自动修改。

已选代理的单次请求不会因失败重新解析成 DIRECT。若系统设置随后改为 DIRECT，默认模式下的新请求会跟随新设置；需要跨刷新保持禁止直连时，应开启「必须代理」。

**本轮保护额度查询，不包括 WebKit 登录网页、其他服务商、Codex 子进程或其他主动探针。** 本地日志/缓存读取不受影响。保护的是应用请求不绕开选定代理；代理服务器内部的路由选择和代理主机自身的 DNS 配置不由 TokenClock 控制。

代理配置明确但无效/冲突时仍暂停，不把配置错误当作“未配置代理”。失败提示统一说明没有自动切换路径，避免对正常直连的失败请求错误宣称“未尝试直连”。

## 验证

- 79 项纯配置检查：默认偏好、开关持久化、默认 DIRECT/TUN 接受、强制模式拒绝无代理、固定系统代理、进程/Claude 配置、配置冲突和移除、PAC 拒绝、合法目的地址、凭据不进入参数、默认配置和绕过变量不能改变请求。
- 18 项真实本地套接字模拟：IPv4/IPv6，成功、502、407、连接关闭、正文传输中断、超时、端口关闭、TLS 证书错误和重定向。成功请求经过假代理；所有场景模拟目标端的直连次数均为 0。
- 新增 8 项路由策略套接字模拟（IPv4/IPv6）：默认直连与模拟 TUN 配置正常完成；开启强制模式则在联网前阻止。这是 TUN 配置选择分支的模拟，没有创建真实 TUN，也不代表验证了 VPN 的 kill switch。
- 模拟包含 `NO_PROXY=*` 和诱导直连/跟随重定向的假 `.curlrc`；请求不受它们影响。
- TLS 模拟使用临时证书，仅独立测试程序通过编译标记允许指定本地测试 CA；不修改系统信任库。应用构建没有这项测试入口。
- 22 项实际额度服务检查：两种 Cookie 来源与 OAuth 路径的代理拦截状态、空额度、不要求重新登录，以及原有成功数据解析。
- Glass Release 构建通过。全程没有使用真实账户凭据、访问 Claude 额度接口或生成模型请求，模型费用为零。

网络检查可以单独运行，不依赖 XCTest：

```sh
python3 scripts/test_claude_quota_proxy.py
```
