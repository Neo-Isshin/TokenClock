本轮补齐 macOS Normal 和 Linux，功能以已发布 Glass v1.6.3 为基准；保留 Normal 主题与 Linux 原生样式。Windows 等待自有测试机恢复在线，暂不发布未经验证的新包。

### 本轮对齐 / Edition parity

- 同步工具与模型归一化、新 harness、只读日志、并发归属、缓存与 API 等价费用／Fast 拆分；t/s 仍每 3 分钟刷新，TTFT 只使用真实时间记录。
- 补齐总结面板、6h/24h 小时图、昨日同期、缓存与额度时间线、行事本、AI速递、通知分类与已读，以及可编辑快捷按钮。
- 补齐网络／本地工具箱、按需检测、增量／全面扫描、上次结果、脱敏 API key 验活；普通超时不判为 GFW 封锁。
- 同步真实 Claude App 额度缓存、共享 X 周额度／去重、多账号选择、最多四个额度选项两两分页与 Antigravity 三类额度。
- 面板边缘拉伸、悬停、分享周期／缓存开关、自然风光背景与 Ailyre 品牌同步；保持各平台原有表盘设计与文字颜色规则。

### 平台说明 / Platform notes

- **macOS Normal**：Apple Silicon / Intel 通用包，最低 macOS 12；保留 Normal 主题、表盘及配色。Glass 专属透明材质继续保留在 Glass。
- **Linux**：GTK / Cairo 原生界面，按原有原生菜单进入总结。浏览器 DNS / WebRTC / DoH 检测打开 Ailyre 完整检测页；本机出口、IPv6、地区、AI 分流与 Globalping 对照在原生窗口展示。模型检测使用同一打包的本机 worker 和浏览器界面，启动服务不会自动提交模型请求。
- Linux Grok Bot 兼容现有 OSCrypt v10/v11 记录；桌面 Secret Service 后台不请求解锁，只有主动授权可请求目标密钥解锁。未知存储格式不会伪造额度或反复弹授权。
- Claude 读取原 App 已保存的真实记录并保留采样时间。无有效记录、组织不明或上游拒绝时保持不可用，不估算云端聊天 Token；反馈用户设备的在线成功读取尚未实测。
- Logs remain read-only. Public macOS packages retain the historical ad-hoc, non-notarized format; private local signing material is never distributed.
- No GitHub Actions tests are used. Native validation runs on the local Mac and owned Debian; Windows testing is paused at the user's request.
